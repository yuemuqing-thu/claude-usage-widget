## 配文（可直接发）

### 标题

> 本来想看AI用量，结果在Mac上养了猫

备选：`做了个用量挂件，最认真改的却是猫`

### 正文

这个项目一开始真的只是想看用量。

把 Claude 和 Codex 已经用了多少、什么时候恢复，放在 Mac 桌面上，省得老去翻。

后来觉得桌面有点空，加了只猫。

再后来，就开始纠结它的嘴为什么这么怪、睡觉怎么还睁着眼、走路为什么像在滑冰……

改来改去，现在它会跟着鼠标跑，点一下会眯眼冒爱心。可以喂鱼、逗毛线球，放个激光点让它追。摸熟了还能给它起名字。

正事也没落下：Claude / Codex 可以切换，5 小时和 7 天额度都能看，还有最近两周的用量趋势。平时缩成一小条，想看细节再展开。

目前只做了 macOS，要配合本机的 Claude Code 或 Codex 使用。读的是本地记录，不用再填账号密码，也不上传数据。

免费，代码也放 GitHub 了，安装方法在 README：
`yuemuqing-thu/claude-usage-widget`

养不了真猫，先往桌面放一只。

## 素材来源与重新导出

`shot-expanded.png` 和 `shot-pill.png` 是仓库已有的历史实拍，未修改画面中的用量数值；
尚未补拍含双页签的新版截图。这组图适合先审版，发布前建议按下方清单换成当前版本。
`04-cat` 的三个姿态则直接来自当前产品代码。生成器仅供制作素材，不是用户安装依赖。

```sh
node docs/xiaohongshu/build-social.js
```

再用 macOS Quick Look 将六张 SVG 导出为 1080×1080 PNG。SVG 已内嵌截图，可单独打开。

## 20 秒录屏分镜

1. **0–2 秒**：空桌面，鼠标移动，猫跟过来。字幕：「我在 Mac 桌面上养了只猫」。
2. **2–5 秒**：鼠标移到折叠的额度药丸，点开。字幕：「它顺便帮我看 AI 额度」。
3. **5–9 秒**：在 Claude / Codex 页签间切换，停在两个环上。
4. **9–12 秒**：向下展示 14 天柱状图和 91 天热力图。
5. **12–17 秒**：打开猫爪面板，依次点小鱼、毛线球、激光点；每个动作只留最有趣的 1 秒。
6. **17–20 秒**：收回卡片，猫继续在桌面走。字幕：「免费开源 · GitHub 见」。

录制建议：尺寸 1920×1080，30 fps，先关闭桌面通知；编辑时裁成 1080×1440，
不要用快速晃动的镜头，每个交互都让观众看清一次。
