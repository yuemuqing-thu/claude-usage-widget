# v0.3.6

Codex 用量过滤更严格：只有 `type` 字段值为 `token_count` 的记录才参与统计，避免把其他记录里的同名标签计入用量。升级后会重建 Codex 派生缓存，原始会话文件不受影响。

- 修正 doctor 把模型／累计值元数据当统计行的问题。抽样无用量时显示说明，不再直接报格式错误。
- 中英 README 增加人工核对指南，解释 Codex “剩余比例”与挂件“已用比例”的换算。
- 新增六张小红书宣传图、发布文案及录屏分镜；截图保持原比例，猫使用产品中的实际精灵。
- 更新交接文档，区分已验证的本地解析和仍待人工完成的同时间对照。

验证：Shell 语法、变量 lint、Codex 数据回归通过。新增非用量样例在旧解析器上会污染计数，在新版中被忽略。

更新已有安装：

```sh
brew update
brew upgrade yuemuqing-thu/tap/claude-usage-widget
claude-usage-widget install
```
